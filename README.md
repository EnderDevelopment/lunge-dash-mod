# Lunge Dash Mod

Enhance your Minecraft experience with a powerful lunge dash ability.

## Features

- Lunge dash ability using a trident
- Client-side mod for enhanced gameplay

## Requirements

- Minecraft 1.21.1
- Fabric Loader 0.14.0 or higher
- Fabric API

## Installation

1. Download the latest version of the mod from the [releases page](https://github.com/EnderDevelopment/lunge-dash-mod/releases).
2. Place the downloaded JAR file in your `mods` folder.
3. Launch Minecraft with the Fabric profile.

## Usage

1. Launch Minecraft with the Fabric profile.
2. Ensure you have a trident in your inventory.
3. Press the left mouse button to perform a lunge dash.

## Configuration

The mod does not require any configuration files. Simply install and use.
